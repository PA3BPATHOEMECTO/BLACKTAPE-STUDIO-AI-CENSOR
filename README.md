## 1. О ПРОЕКТЕ

**BLACKTAPE Studio** — это комплексная цифровая звуковая экосистема нового поколения, объединяющая нейросетевую обработку вокала, студийный звуковой DSP-движок, соответствие законодательным нормативам РФ, генератор слогового караоке TTML, хранилище сэмплов с интерактивным спектральным аудиоплеером и защищенный мессенджер артистов.


---

## 2. КЛЮЧЕВЫЕ МОДУЛИ И ВОЗМОЖНОСТИ

### [ 01 ] НЕЙРОСЕТЕВАЯ ЦЕНЗУРА ТРЕКОВ (149-ФЗ РФ)
* **Разделение дорожек студийного уровня**: изоляция чистого вокала и инструментала на базе нейросети UVR-MDX-Net Voc FT.
* **Автоматическое сканирование контекста**: выявление обсценной лексики, запрещенных веществ и экстремистских формулировок по словарям и фонетическим алгоритмам.
* **Гибкая цензура**: интеллектуальное заглушение (Mute) или студийный Bleep-сигнал с сохранением темпа, ритмики бита и исходного инструментала.
* **Экспорт**: WAV 24-bit Lossless, MP3 320 kbps, FLAC, M4A.

### [ 02 ] ГЕНЕРАТОР ПОСЛОГОВОГО КАРАОКЕ TTML & LRC
* **Слоговая синхронизация**: высокоточный тайминг вокальных партий для стриминговых платформ (Apple Music, Яндекс Музыка, VK Музыка).
* **Интерактивный плеер**: предварительное прослушивание трека в реальном времени с подсветкой активных слов и слогов.
* **Экспорт**: форматы `.ttml` (Apple Music specification) и синхронизированный `.lrc`.

### [ 03 ] СТУДИЙНЫЙ АУДИО ЛАБ // DSP FX
* **Нейромастеринг**: динамическая нормализация громкости под стриминговые стандарты (-14 LUFS для Spotify/Apple Music).
* **Студийные эффекты**: Stereo Widener, Tape Saturation, Pitch & Formant Shifter, Peak Limiter, эквализация.
* **Детекция характеристик**: определение тональности (Key) и темпа трека (BPM).

### [ 04 ] МЕДИА ЛАБ // ВИДЕО-ВИЗУАЛИЗАТОР
* **Реактивный спектральный рендер**: процедурная визуализация аудиопотока в реальном времени.
* **Киберпанк-шаблоны**: неоновый цифровой дождь, частотные осциллографы, минималистичные волны.
* **Экспорт**: готовые видеофайлы MP4 (1080p, 60 FPS) для сниппетов, Shorts, Reels, TikTok.

### [ 05 ] КАТАЛОГ СЭМПЛОВ // SAMPLEFOCUS-GRADE PLAYER
* **Аудиовизуализация**: 85-полосная частотная спектрограмма реального аудиосигнала (Web Audio API).
* **Hover-to-Play**: мгновенное воспроизведение сэмпла при наведении курсора и остановка при отводе.
* **Интерактивный скраббер**: перемещение по таймлайну кликом, фиксация прослушивания (Pin Play).
* **Жанровая классификация**: фильтрация по жанрам и кастомным поджанрам, загрузка в 24-bit Lossless.

### [ 06 ] ДРАМ-ВОЛТ // ХРАНИЛИЩЕ ДЛЯ БИТМЕЙКЕРОВ
* **Каталог паков**: 808-басы, снэйры, хэты, перкуссия, ван-шоты и драм-лупы.
* **Поддержка архивов**: лимит на загрузку авторских паков до 500 МБ.
* **Модерация контента**: строгий контроль качества авторских материалов перед публикацией.

### [ 07 ] ЗАЩИЩЕННЫЙ МЕССЕНДЖЕР И СООБЩЕСТВО
* **Диалоги и каналы**: официальный канал студии BLACKTAPE HUB, общий лаунж и сквозные личные чаты (DMs) между зарегистрированными артистами.
* **Вложения**: отправка аудиофайлов, треков со встроенным веб-плеером, скриншотов, архивов и проектных файлов.
* **Профили артистов**: персональный ID, настраиваемый баннер, аватарка (поддержка GIF), социальные ссылки (VK, Telegram, Soundcloud, Spotify) и статус.

## 3. ЮРИДИЧЕСКИЙ КОМПЛАЕНС (РФ)

BLACKTAPE Studio функционирует в строгом соответствии с законодательством Российской Федерации:
* **Статус информационного посредника (Ст. 1253.1 ГК РФ)**: автоматизированный технологический DSP-инструмент.
* **Федеральный закон № 152-ФЗ**: регламентированная защита персональных данных артистов.
* **Федеральный закон № 149-ФЗ**: модуль подачи обращений правообладателей (Notice & Takedown) для оперативной блокировки спорных материалов.

## 4. ТЕХНОЛОГИЧЕСКИЙ СТЕК

* **Backend**: Python 3.12, FastAPI, Uvicorn, SQLite (WAL Mode, Async Engine), UVR AI Core, PyTorch.
* **Frontend**: Vanilla JavaScript (ES6+), Web Audio API, Canvas API, CSS3 Architecture (Zero heavy dependencies).
* **Web Server & Reverse Proxy**: Nginx (Brotli/Gzip Static, Rate Limiting, Client Max Body 650M, SSL/TLS).
* **DevOps**: Systemd, Certbot (Let's Encrypt), Cloudflare Zero Trust.

## 5. ЛОКАЛЬНЫЙ ЗАПУСК И УСТАНОВКА

### Требования:
* Python 3.10+
* FFmpeg (в системном PATH)
* Git

### Установка:
```bash
# Клонирование репозитория
git clone https://github.com/<ВАШ_АККАУНТ>/blacktape-studio.git
cd blacktape-studio

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/macOS
# venv\Scripts\activate   # Windows

# Установка зависимостей
pip install -r requirements.txt

# Запуск локального сервера разработки
python run_server.py
```
Сервис будет доступен по адресу: `http://localhost:8088` (или `http://localhost:8080` при использовании Nginx).
